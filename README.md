# SgrMystiaAssistant

**SgrMystiaAssistant** 是一个为游戏《[东方夜雀食堂](https://store.steampowered.com/app/1584090/)》开发的**辅助 Mod**。

SgrMystiaAssistant 可以在营业场景中实时地显示稀有客人喜欢的食物和酒水tag，以及厌恶的食物tag.

可以配合四人联机mod一起食用➡️https://github.com/ShigureYuki/SgrMystia

## 安装与使用

1.打开BepInEx BE的官方构建页面： https://builds.bepinex.dev/projects/bepinex_be

2.在页面中选择适用于《东方夜雀食堂》的il2cpp版本（BepInEx Unity (IL2CPP) for Windows (x64) games）。 **注意：本游戏使用的是il2cpp，请选择对应版本，否则无法正常运行。**

3.下载完成后，将压缩包解压到游戏根目录。

4.将*SgrMystiaAssistant.dll* 放入 *游戏根目录/BepInEx/plugins*

5.启动游戏，在夜间营业场景中按下**H**键即可启用/禁用小助手

**注意，小助手默认是禁用状态。**
